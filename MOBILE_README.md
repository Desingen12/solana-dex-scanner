# Solana DEX Scanner - React Native iOS

👋 Willkommen zur mobilen Version!

## Quick Start

```bash
# 1. Dependencies installieren
cd mobile
npm install

# 2. App starten
npm run ios
# oder
npm start
```

Das war's! Die App startet im iOS Simulator oder Expo App.

## Branches

- **main** - Web App (Next.js)
- **react-native-ios** - Mobile App (React Native)

## Features

✅ Token Suche (DEXScreener)
✅ Phantom Wallet Connect
✅ Portfolio Management
✅ SOL Balance Tracking
✅ 24h Price Changes
✅ Liquidity & Market Cap

## Struktur

```
mobile/
├── screens/       # 4 Main Screens
├── components/    # TokenCard
├── services/      # APIs
├── store/         # Zustand State
```
