# 🚀 Solana DEX Scanner

A real-time token scanner for the Solana blockchain. Search and track tokens with live prices, liquidity, and market cap data.

## Features

✅ **Real-time Token Search**
- Search by token symbol or mint address
- Live price updates from DEXScreener API
- 24h price changes
- Liquidity & Market Cap info

✅ **Lightning Fast**
- Built with Next.js 14
- Server-side rendering
- Optimized for mobile

✅ **Zero Dependencies**
- No wallet adapter issues
- No complex peer dependencies
- Clean, maintainable code

## Tech Stack

- **Next.js 14** - React framework
- **TypeScript** - Type safety
- **CSS Modules** - Scoped styling
- **DEXScreener API** - Token data

## Quick Start

### Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

### Build for Production

```bash
npm run build
npm run start
```

## Deploy to Vercel

1. Push to GitHub
2. Go to [vercel.com](https://vercel.com)
3. Import repository
4. Click "Deploy"
5. Done! 🎉
